# Form Validation (HTML & CSS)

A simple and responsive form validation project built with HTML5 and CSS3. This project demonstrates how to use built-in HTML validation attributes and CSS styling to guide user input and improve user experience.

## ✨ Features

- HTML5 input validation
- Real-time feedback using `:valid` and `:invalid` pseudo-classes
- Custom error messaging and placeholder guidance
- Responsive and modern UI design

## 📁 Technologies Used

- HTML5  
- CSS3
